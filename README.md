# Huizhong Wang — Academic Homepage

Minimal, responsive academic homepage for GitHub Pages.

The information architecture is adapted from the CC0-licensed
[Minimal Light](https://github.com/yaoyao-liu/minimal-light) academic homepage
template. The page uses plain HTML and CSS, with no runtime dependencies.

The live site will be available at <https://huiz-w.github.io/> after GitHub
Pages is enabled for this repository.
